## 실행 방법

1. VS Code에서 폴더 열기
2. Live Server 확장 설치 후 `Go Live` 클릭
3. 브라우저에서 자동으로 열림

---

## API 정보

- 제공: Open-Meteo (https://open-meteo.com)
- 비용: 완전 무료, API키 불필요
- 지원 데이터: 현재 날씨, 시간별/일별 예보
- 지원 도시: 서울, 부산, 대구, 인천, 제주, 영천 등

---

## 주요 기능

- 도시 검색 및 빠른 선택 버튼
- 현재 기온, 날씨 상태, 날씨 아이콘
- 습도, 풍속, 체감온도, 구름량, 강수량, 가시거리
- 시간별 예보 (12시간)
- 반응형 레이아웃
